# Experiments

Design explorations and prototypes that are **not part of the shipping codebase**.
Nothing in this directory is built, linked, or imported by the client or server.

- `friend-list-mockups/` — HTML mockups of four design directions for the main
  Vibes friend-list screen (macOS app). Open `index.html` in a browser and use
  the tabs at the top to switch between designs.
- `hero-flow/` — full-screen procedural WebGL take on the hero ribbon graphic
  (animated flow, iridescent dispersion, mouse parallax). Self-contained
  `index.html`; settings overlay toggled with `H`, theme with `T`.
