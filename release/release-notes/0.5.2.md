# Vibes 0.5.2

A friendlier first run, and a calmer window.

- Getting started is guided: a gentle arrow points you to adding your repos, then to inviting your first friend.
- Invites are personal: the invite screen now shows who invited you by name.
- New text size setting (Settings → General) makes the feed easier to read — it starts one notch larger.
- Cleaner look: simpler setup screen, refreshed rounded controls, and a quieter status bar that only speaks up if sync has a problem.
