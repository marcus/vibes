# Vibes 0.9.0

Hide a project without losing it.

- New eye toggle next to each repository in Settings lets you temporarily hide a project. A hidden project stops contributing to your shared activity and drops out of your friends' feed, and you can bring it back any time.
- Repository rows stay on a single tidy line.
