# Vibes 0.3.0

App-first onboarding. Setup is now a single step, and friends connect through one-time invite links.

- First launch just asks for a display name. Vibes creates your identity on your Mac — no token to copy.
- Add a friend by sending a one-time invite link. They open it and you're connected.
- Invite links open Vibes directly when it's installed, or show a code to paste after download.
- Token-based setup is still available under Advanced for existing accounts and extra Macs.
