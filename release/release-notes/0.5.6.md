# Vibes 0.5.6

Your daily activity is now commits-only.

- Fixed: a repo with leftover uncommitted edits no longer shows as "worked on today" — only commits you actually made today count toward your stats and project tags.
- Fixed: profile icons in the orbit view no longer show cropped edges while gently floating.
