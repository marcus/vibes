# Vibes 0.7.0

- Adds commit streaks: a quiet "N day streak" label next to your commit count when you've committed on consecutive Vibes days.
- Counts a streak day as any day with at least one commit, summed across all your Macs, so multi-device days count once.
- Shows streaks only when your Git stats are visible, and only once a streak reaches two days — a gentle "still building" cue, not a score.
- Keeps streaks private: friends receive only the current day count, never a calendar, missing-day history, repo paths, branches, commit messages, filenames, or device details.

Privacy note: Vibes shares aggregate daily Git stats only; it does not share raw paths, branch names, commit messages, filenames, or tokens.
