# Vibes 0.11.1

Your commits now count even if you never configured a git email, and Vibes tells you when a repo can't be scanned instead of staying silent.

- Fixes repos showing zero activity forever on Macs without `git config user.email` set — Vibes now uses the same author identity git itself uses for your commits.
- Repo settings now show a warning badge (with an explanation on hover) when a repo folder is missing, isn't a git repository, has no resolvable git identity, or when today's commits were made under a different email.
- Adding a folder that isn't a git repository now tells you right away instead of silently accepting it.
- Diagnostics now include a per-repo health line so problems are visible at a glance.
