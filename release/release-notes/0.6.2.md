# Vibes 0.6.2

- Improves multi-Mac Git stats accuracy by deduplicating the same pushed or pulled commit across devices.
- Scans all local branches for the Vibes day so branch switching no longer hides same-day commits.
- Keeps Git details private: friends still receive aggregate counts only; raw commit hashes, branch names, messages, filenames, and repo paths are not shared.
- Stores narrow daily commit history on the relay for future streak and baseline features without exposing fingerprints in the feed.

Privacy note: Vibes shares aggregate daily Git stats only; it does not share raw paths, branch names, commit messages, filenames, or tokens.
