# Vibes 0.10.3

Fixes duplicate windows and evening activity readings.

- Vibes now keeps a single main window. Showing Vibes or starting an invite no longer stacks up extra copies of the window, each with its own invite sheet.
- Your network pulse no longer goes quiet late in the evening.
