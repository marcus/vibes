# Vibes 0.7.1

A reliability fix for scanning local repositories.

- Fixed: scanning a repository with a lot of activity could hang the app — a spinning wheel that never finished, and on the next launch the window might not appear at all. Repository scans now run in the background, can't stall the app, and give up gracefully on any repo that takes too long.
